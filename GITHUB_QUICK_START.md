# Revit MCP - Setup Instructions

## 🚀 Quick Start

Choose your setup method:

### **Option 1: Automated Setup (Recommended)**

#### Windows:
```bash
./quick-setup-secure.bat
```

#### Linux/Mac:
```bash
chmod +x quick-setup-secure.sh
./quick-setup-secure.sh
```

> This will auto-generate your API key, certificates, and configure everything!

### **Option 2: Manual Setup**

```bash
# 1. Copy config template
cp .env.secure-example .env

# 2. Generate API key
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
# Copy output to MCP_API_KEY in .env

# 3. Generate certificates
mkdir -p certs
openssl req -x509 -newkey rsa:4096 -keyout certs/server.key -out certs/server.crt -days 365 -nodes

# 4. Install dependencies
npm install

# 5. Start server
node server-secure.js
```

## 🔐 Configuration

Edit `.env` file to customize:

```env
# Default (Localhost Only) - Most Secure
MCP_HOST=127.0.0.1
MCP_APIey=<auto-generated>
ENABLE_IP_WHITELIST=false
ENABLE_RATE_LIMIT=true

# For Network Access - Edit as needed:
MCP_HOST=0.0.0.0                    # All interfaces
ENABLE_IP_WHITELIST=true
WHITELIST_IPS=192.168.1.0/24        # Your network CIDR
ENABLE_RATE_LIMIT=true
RATE_LIMIT_REQUESTS=100             # Per minute
```

See `SECURITY_GUIDE.md` for all options.

## ▶️ Starting the Server

### Direct Node.js
```bash
node server-secure.js
```

### Using PM2
```bash
npm install -g pm2
pm2 start ecosystem-secure.config.js
pm2 logs revit-mcp-secure
```

### Using Docker
```bash
docker-compose up -d
docker-compose logs -f revit-mcp
```

## 🔌 Connecting Claude Desktop

Edit your Claude config file:

**Location:**
- Windows: `%APPDATA%\Claude\claude_desktop_config.json`
- Mac: `~/Library/Application Support/Claude/claude_desktop_config.json`
- Linux: `~/.config/Claude/claude_desktop_config.json`

**Configuration:**
```json
{
  "mcpServers": {
    "revit-mcp": {
      "url": "https://localhost:3000",
      "env": {
        "Authorization": "Bearer YOUR_API_KEY_HERE"
      }
    }
  },
  "preferences": {
    "coworkScheduledTasksEnabled": false,
    "sidebarMode": "chat"
  }
}
```

Replace `YOUR_API_KEY_HERE` with the key from your `.env` file.

## ✅ Verification

```bash
# Health check (no auth needed)

# Status check (requires auth)
API_KEY=$(grep MCP_API_KEY .env | cut -d'=' -f2)
curl -k https://localhost:3000/status -H "X-API-Key: $API_KEY"
```
